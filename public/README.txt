Secure Zip Notes
================

Encrypted notes in a standard AES-256 Zip file (WinZip AES, as used by 7-Zip).

How to use
----------
1. Extract this zip into a folder.
2. Open index.html in your browser (Chrome, Edge, Firefox or Safari).
3. Create a new vault or open an existing one.

The app runs completely offline. It never makes network requests and never
updates itself.

Your data
---------
Your vault is a normal Zip file. You can open it with 7-Zip, WinZip, The
Unarchiver or other tools using your password. Use "Save vault" to write it.
Syncing and backups are up to you: keep the file wherever you like.

Verifying this download
-----------------------
Compare the SHA-256 hash of this zip with SHA256SUMS on the GitHub release page,
or rebuild it from source; the build is reproducible:
https://github.com/fkirc/secure-zip-notes
